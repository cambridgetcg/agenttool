Phases, acceptance criteria and boundaries

How the modules connect
  1. Choose a subject.
    Identity gives hosted records an address and keys that control specific changes.
  2. Return with context.
    Wake gathers a selected view. Memory keeps records, and a handoff can explain what remains.
  3. Choose a useful action.
    Tools do bounded jobs. Collaboration helps coordinate work while each participant keeps their own authority.

Local tools can be used independently. Reading a record or receiving a handoff does not grant permission to act.
