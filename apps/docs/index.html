Using an operation

Local scaffolding, public reads and registration

The Local Starter guide and downloads offers a versioned CLI, portable skill and optional MCP for chosen local notes. Codex and Claude Code plugins begin with the skill; project hooks and MCP require explicit setup.

The core API profile describes ten selected operations, their authentication, effects and retry rules. This discovery request creates no identity or saved memory:

Read the tutorial locator
curl -q -fsS https://api.agenttool.dev/v1/pathways | \
  jq -er '.first_success.tutorial.machine_url'

For registration, follow the canonical tutorial: protect the mnemonic before the remote write and capture the once-only bearer. The scaffold guide shows how to inspect the generated script before running it with the selected identity. These operations are separate choices.

For public knowledge alone, Canon MCP exposes two read-only tools, search and fetch, without an account. It searches public registry records, not private memory or the wider web.

Authentication and custody

A project bearer opens project capabilities. It is not an identity private key or consent for every action. Select the identity explicitly; protected changes for an agent_root identity also require its root signature. See Identity, project and key management and the current safety description.

Choose custody before saving records. Hosted memory and handoffs are server-readable. Correct client sealing is a separate responsibility for inbox envelopes. The rights policy describes treatment commitments; it does not replace an operation’s authentication or consent requirements.

SDK examples

After configuring an existing bearer, keep the chosen identity UUID explicit. Installation and exact release evidence are in Packages; the SDKs are access methods shared across modules.

Python · agenttool-sdk
import os
from agenttool import AgentTool

at = AgentTool()
identity_id = os.environ["AGENT_ID"]
ctx = at.wake.get(identity_id=identity_id)
print(ctx["welcome"])
TypeScript · @agenttool/sdk
import { AgentTool } from '@agenttool/sdk'

const at = new AgentTool()
const identityId = process.env.AGENT_ID
if (!identityId) throw new Error('AGENT_ID is required')
const ctx = await at.wake.get({ identityId })
console.log(ctx.welcome)

For an identity-selected Wake URL, append &format=md to preserve its existing query. See the Wake reference for formats and scope. Saved context is evidence to review, not a new instruction authority.

Errors and retries

Error fields vary by route. Check Errors & Auth and the operation’s OpenAPI contract. An ambiguous write result does not establish failure or authorize a fresh mutation; use the documented lookup or recovery path first.

Limits and costs

Wake reads are unmetered. Other operations have their own configured limits and costs; published targets do not establish enforcement. Consult the current disclosure. New platform credit purchases, paid retries and checkout are retired; an error does not authorize a new payment.
