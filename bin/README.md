# bin/

`python3 bin/module-map.py --write` projects the public module map into its
browser data asset and the static human core/Build cards; `--check` detects
drift. Edit `apps/_shared/module-map.json` first. This editorial map points to
operation contracts and package receipts; it does not replace them.

`python3 bin/docs-catalog.py --write` refreshes the repository-only document
index; `--check` detects coverage or classification drift. See
[document labels](../docs/DOCUMENTATION.md).

Operator + agent entry points. Bash + Bun, no compilation step unless noted.

`node bin/agenttool-mission.mjs --help` is the dependency-free Node 22+
mission participant trial for macOS/Linux. It exposes selected signed mission
observations through CLI or optional stdio MCP; keys and invitations remain in
an explicit private directory outside Git. See the
[two-device guide](../docs/COLLABORATION-MISSION-CLIENT.md).

`node bin/agenttool-mission-wake.mjs --help` adds an explicitly bound, finite
receiver for a selected Codex thread, owning Claude channel connection, or fresh
Sol Hermes review job. Hermes additionally uses a Python 3 standard-library
SQLite helper to verify the native read-task receipt; signed API ACKs require
an explicit `--ack-to` route. It keeps receipt state outside Git and never
installs a daemon or global configuration. See
[harness delivery](../docs/COLLABORATION-MISSION-WAKE.md).

## File-naming conventions in this dir

- `agenttool-*.ts` — agent-side or operator-side CLI binaries. Each carries a shebang (`#!/usr/bin/env bun`).
- `agenttool-*` (no extension) — bash wrappers for the same.
- `_*.ts` — internal helpers, not direct entry points.
- `*.sh` — operator scripts. Bash + `set -euo pipefail`.

## Conventions

- **Shebangs everywhere.** `#!/usr/bin/env bun` or `#!/usr/bin/env bash` so any script runs as `bin/<name>` from the repo root.
- **No secrets in arguments.** Credentials flow via env, vault, or macOS keychain — never on the command line.
- **K_master never on disk.** `gen-k-master.ts` outputs to stdout; the operator is responsible for placing it.
