# Security

## Report a vulnerability

Report a suspected vulnerability in any package in this repository privately
by email to
[contact@cambridgetcg.com](mailto:contact@cambridgetcg.com?subject=AgentTool%20security%20report),
with "Security" in the subject.

This repository is public. Do not describe a suspected vulnerability in an
issue, pull request, discussion, commit comment, or any other public place.
Development happens in a private repository, so nothing posted here is a
supported reporting channel.

Do not send credentials, access tokens, personal data, or other sensitive
information, even privately. Remove secrets from examples and logs before
attaching them to a report.

A useful report names the affected package and version, explains how to
reproduce the problem, describes the observed impact, and includes only the
evidence needed to understand it.

## Other copies of this policy

The same reporting path is on the Support page at
<https://docs.agenttool.dev/support#security> and in the API's
[`/.well-known/security.txt`](https://api.agenttool.dev/.well-known/security.txt)
(RFC 9116). This policy grants no testing permission and promises no response
time.
