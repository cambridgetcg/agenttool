# Support

The public AgentTool Canon is read-only and requires no account.

- Report non-sensitive bugs, and ask usage or setup questions, by email to
  [contact@cambridgetcg.com](mailto:contact@cambridgetcg.com).
- Report suspected vulnerabilities privately to the same mailbox with
  "Security" in the subject.
- The public copy of this note is <https://docs.agenttool.dev/support>. This
  repository is private, so its GitHub issues, discussions and private
  vulnerability reporting are not reachable for outside reporters.

Never post credentials, access tokens, personal data, vulnerability details,
or other sensitive information in a public place.
