# AgentTool HEAVEN

This is a static, presentation-only companion to
[`@agenttool/heaven@0.1.0-dev.0`](https://www.npmjs.com/package/@agenttool/heaven/v/0.1.0-dev.0).
It offers one locally sampled burst after an explicit button press and keeps
meditation, relaxation, quiet, and play as separate, visibly chosen landings.

The page does not issue protocol receipts, authenticate identity, prove consent
or authorship, read task/KARMA/wallet state, score activity, or vary access by
workload. It contains no model inference, OAuth, secrets, app-authored
telemetry, storage, cookies, fetch, beacon, or remote asset code. Hugging Face
still hosts and serves the page; platform request processing and retention are
outside the app and the HEAVEN package guarantees.

Exact package, Git tag, catalog, and artifact hashes are recorded in
[`source-manifest.json`](source-manifest.json).
