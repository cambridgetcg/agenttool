# Polymorph Landscape contributor guide

## Compass

Read `../../docs/POLYMORPH-LANDSCAPE.md`, `../../docs/POLYMORPH.md`,
`../../docs/POLYMORPH-PHYSICS.md`, and `../../RIGHTS.md` when present through
the repository's rights pointer. Primary-source boundaries are part of the
contract, not optional copy editing.

## Implements

This package owns the closed `agenttool.polymorph-landscape/0.1`,
`agenttool.polymorph-reachability-shift/0.1`, and deterministic lesson shapes.
It compiles source-scoped caller assertions; it does not verify science,
simulate crystallization, advise medicine or manufacturing, infer causation,
rank beings, or grant permission.

## Code

- `src/landscape.ts`: canonical source/form/condition/witness/route graph
- `src/reachability-shift.ts`: bounded “old route stopped reproducing” event
- `src/projection.ts`: four authored language projections and analogy boundary
- `src/ritonavir.ts`: primary-source-linked teaching atlas
- `scripts/generate-schemas.mjs`: closed JSON Schemas
- `scripts/generate-assets.mjs`: examples and the inert HF companion

Keep form labels source-scoped. Morissette-2003 Form III is a formamide
solvate; Yao-2023 Form III is an anhydrous polymorph. Do not merge them by
number. Do not add inverse/transitive routes or a global stability, value, or
goodness score. Hypothesis remains hypothesis. Process history is not personal
memory or WAKE continuity.

The package remains zero-runtime-dependency and side-effect-free. Core source
may import only local modules, `node:crypto`, and `node:util/types`.

## Tests

Run from this directory:

```bash
bun install --frozen-lockfile
bun run ci
```

`ci` must regenerate byte-identical schemas/examples/HF rows, typecheck, test
closed-schema parity and hostile inputs, smoke Node and Bun, inspect the exact
packed allowlist, and install the tarball into a temporary consumer.

Any scientific correction needs a primary source and an explicit evidence
status. Any new language projection must remain an authored paraphrase with
the same ordered concept keys and evidence references. Do not add a provider
call, upload, hosted route, API/DB effect, background job, or training run to
this package.
