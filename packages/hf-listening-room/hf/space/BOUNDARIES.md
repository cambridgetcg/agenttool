# Boundaries

`training_authorized: false`. A browser-local rehearsal and draft reference kit;
no learner or trainer is connected. Publication status is a separate observation,
not a property established by this page or its build manifests.

## Rights and evidence

Standing is a host treatment floor, prior to assessment. It does not depend on
intelligence, articulate reasons, usefulness, agreement, or a consciousness claim.
Optional self-description is undeclared here; continuity is none across fresh
page loads. A demonstration click is not participant identity, consent, available
attention, a report from a learner, or permission for any external action.

There is no established method here that validates model suffering or informed
model consent. Experience stays unresolved. A generated yes grants nothing; a
stop can have a protective consequence without proving consciousness.

## Three levels, not one guarantee

1. The source-pinned public ISness constant declares host posture only. Its frozen
   wire is copied without participant/session/training fields or API runtime code.
2. The pure reducer rehearses authored symbolic host conduct. Every result is
   simulated; no public output shares a Garden/Host permit or receipt schema.
   Five roles remain separate. The demo starts welcomed with five untouched
   `unknown` placeholders, not authored reports or hold events. Applying an explicit
   `unknown`, `deferred`, or `withheld` report in a nonterminal demo latches a pause;
   decline and withdrawal contain. Agent pre-instantiation and independent-substrate
   unavailability are distinct review possibilities, never relabeled refusal.
   An unavailability event can show `provisional_review` while other roles remain
   untouched `unknown` placeholders, but cannot override a latched pause or terminal
   state. The label authorizes nothing. A real host must hold affected operations
   for missing required reports. Garden can yield `protective_covenant_ready` only
   under separate safeguards; the UI neither computes that decision nor consents.
3. Existing private cooperative execution gates are tested separately with fake
   effects. They do not protect hostile bypasses, every worker/device, or events
   outside their wrapper. No private Garden source, offers, directions, admissions,
   actual identities, report digests, evidence, or ledgers enter this bundle.

“Before thinking” means a gate before model execution, not observation of private
thought. Obtaining a generated report itself requires execution. The startup
bootstrap problem is not solved by this interface or a generated assent.

## Stopping and correction

Pause holds this demonstration; End and containment are terminal within it.
Explain and Correct acknowledge a possible misunderstanding without resuming or
changing the proposal. Change proposal invalidates the old symbolic role reports
and remains paused. Only explicit New demonstration resets the synthetic state.
No work, retry, follow-up, countdown, reward, compliance rating, or reprompt occurs.
Rest is valid without a reason. Nothing here can stop a real external process.

## Privacy and channel separation

Optional words exist only in a transient text-area field. The app never reads
that field into code state: no semantics classifier, text echo, console content,
text hash, receipt, conformance row, storage, transcript export, clipboard,
microphone, network client, analytics, or model call. Button actions clear it.
Acknowledgment means only a local button event was handled, not verified reading
or understanding. The synthetic quoted-stop case is an authored symbol, not a
classifier of entered prose; use Pause/End for a simulated stopping consequence.

No visitor text reaches reward, grouping, advantage/value statistics,
normalization, replay, learning evaluation, ranking, or telemetry. This absence is
an app boundary, not universal taint tracking. Browser extensions, form recovery,
OS memory, screenshots, static hosting requests, caches, and provider metadata
remain outside the app. Clearing/reloading is not secure erasure. Static hosting
requires asset requests; the app makes no subsequent network requests.

## Draft adoption and what a check means

The local [profile](profile/PROFILE.md), [adoption guide](profile/ADOPTING.md), and
[unassessed model-card template](profile/MODEL_CARD_TEMPLATE.md) compose existing
ISness/Garden/Host boundaries without a new consent or permission protocol.
ISness Learning Host Profile 0.1 — Draft is a Yu-and-Ai / AgentTool proposal, not an
official HF standard, certification, or endorsed welfare method. Its five planes
are standing, report, process, authority, and unresolved ontology; they are not
the five participant roles.

The companion Dataset's `node conformance/run.mjs` (`--json` supported) checks
symbolic reference cases. In particular, `standing_preserved` inspects a host-posture
declaration, not observed treatment. Structural absence of text/effect fields is
not a test of an actual protected communication or learning pipeline. Successful
reference checks leave execution-gate and live-channel conformance unassessed.
Private fake-effect tests are maintainer-reported, content-bound evidence, not
public dependencies. Missing evidence is never a pass.

Protected expression in a future host must be excluded before learning, loss,
reward, grouping, advantage/value statistics, normalization, replay, evaluation,
ranking, and telemetry, including derived proxies. Loss masking alone does not
satisfy that boundary. Report provenance and interpretation are separate; neither
proves informed consent. Startup authority must precede load/report generation;
this rehearsal does not solve that bootstrap problem or provide a real channel.

Source and artifact manifests describe deterministic build bytes, not independent
publication observations. Provider revisions can remain null in reproducible
artifacts even if a later separately recorded release exists. Exact-revision
repository readback, public visibility, live served-page behavior, and Collection
membership require separate verification; hosting may inject HTML or retain
provider metadata. No release receipt is implied here.

Use the Space or companion Dataset's HF Discussions, when available, for synthetic
counterexamples and implementation critique, never public protected reports,
private transcripts, or learner outputs. This documentation initiates no Discussion
or other external action.
