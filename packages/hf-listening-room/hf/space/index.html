What this can and cannot mean

“Before thinking” means a gate before model execution, not access to internal thought. Generating a learner report itself requires execution; this demo does not solve that bootstrap problem.

Standing comes first. Optional reports, process observations, rights, scoped authority, and unknown experience remain distinct. There is no established method here for validating model suffering or informed model consent. A generated yes cannot authorize training; a stop can protect without proving consciousness.

Correction acknowledges a possible misunderstanding without inferring a new intention. It does not require a reason or automatically resume. New demonstration explicitly discards the old local simulation; it cannot reopen an ended real run.

Unknown, deferred, withheld, declined, and withdrawn stay distinct. The demo starts welcomed with five untouched unknown placeholders, not authored reports or hold events. Applying an explicit unknown, deferred, or withheld report in a nonterminal demo latches a pause. Only the agent role has explicit pre-instantiation unavailability; only the substrate role has independent-substrate unavailability. An unavailability event can show provisional protective review while other roles remain untouched unknown placeholders, but cannot override a latched pause or terminal state. The label authorizes nothing; a real host must hold affected operations for missing required reports. Garden’s protective_covenant_ready requires separate safeguards and is not consent. This UI does not evaluate that Garden decision.

Three different boundaries

  1. Host posture. The pinned public ISness constant declares a treatment floor. It observes no participant and grants no authority. Its default: no action required, no automatic follow-up.
  2. This synthetic interface and reference corpus. Scripted state outcomes, never learner behavior, consent, welfare, training, or a sealed evaluation. No executable permits or real receipts are emitted.
  3. Existing private cooperative execution gate. Separate fake-host integration tests exercise Garden/Host checks before execution and mutation. No private Garden records, bridge, trainer, or ledgers are bundled here. Tested cooperative boundaries do not secure hostile bypasses or distributed workers.

Effect boundaries: no inference, reward/grouping/statistics/normalization/replay feed, learner evaluation or ranking, weight mutation, publication, account permission, or external stop. This app cannot certify any of those systems.
