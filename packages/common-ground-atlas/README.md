# AgentTool Xenia–Helly Common Ground Atlas generator

This private package deterministically builds and independently verifies the
public-safe, reference-only candidate at `hf/dataset/` for the intended Hub
repository `Yu-and-Ai/agenttool-common-ground`.

The generated Atlas contains three configs and nineteen rows:

- nine exact 2D geometry cases;
- four WAKE freshness and invalidation cases; and
- six public analogy audits.

It is not a solver service or a training package. It performs no provider
operation and grants no publication authority. Every row is synthetic and
marked `training_eligible: false`; that is AgentTool admission metadata, not an
added copyright restriction, and Apache-2.0 governs licensed reuse. The
geometry separates exact rational truth from the shipped teaching lab's
bounded binary64 evidence profile, so an honest `insufficient_evidence` result
can coexist with an exact diagnostic.

Run `bun run ci` to compare generated bytes, validate all three closed JSON
schemas, verify every exact certificate and manifest with JavaScript BigInt,
run the independent standard-library Python verifier, replay the three
numeric-boundary cases against the shipped lab, and exercise hostile
certificate mutations.
