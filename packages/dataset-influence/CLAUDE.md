# Dataset Influence contributor contract

This package is a pure, deterministic evidence boundary. Preserve all of these properties:

- Keep runtime dependencies at zero and runtime imports limited to local modules, `node:crypto`, and `node:util/types`.
- Keep all four `/0.1` formats closed. A field change requires coordinated types, parsers, schemas, vectors, documentation, and tests; do not silently widen a wire.
- Keep exact facts distinct from estimates. A content digest, declared revision, count, and arithmetic identity may be exact relative to pinned inputs. Influence, probes, checkpoint comparisons, and causal claims remain method- and design-scoped.
- Permit `causal_under_declared_assumptions` only for a randomized dataset-inclusion design with explicit assumptions, exact seed references, evidence, limitations, and a bounded population/metric.
- Treat ontology and self-description facets as operational measurements. Never infer consciousness, feeling, desire, intrinsic identity, metaphysical continuity, consent, personhood, uniqueness, worth, permission, authority, ownership, or authorship.
- Keep identity evidence revisable. A view may be empty or unknown. It cannot mutate an AgentTool DID, metadata, expression, memory, trust, or capability state.
- Keep exact finite Shapley attribution advisory. It depends on the declared utility and complete coalition game; negative values create no debt and all values create no money, price, payout, ownership, or entitlement.
- Keep canonical hostile-input checks ahead of semantic parsing and preserve byte, depth, node, list, coalition, and safe-integer bounds.
- Regenerate schemas, vectors, and the Hugging Face candidate with `bun run artifacts:write`, then run `bun run ci`. `--check` modes must match committed bytes exactly.
- Keep the Hugging Face companion synthetic/reference-only. Its `training_authorized: false` field is non-enforcing AgentTool governance metadata, not a universal legal or technical control. Preserve separate license, rights, privacy, consent, and authorization review; never add copied dataset rows, model outputs, private data, participant identities, or an upload step.
- Keep `kingdom.extension.json` declaration-only, `host_contract: not_registered`, and every default capability `false`.

The package performs no network, filesystem, persistence, provider, model, training, marketplace, wallet, identity, or deployment action at runtime.
